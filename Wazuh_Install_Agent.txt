# WAZUH Tools Monitoring

## Tambahkan repository Wazuh
==============================
Jalankan perintah berikut di Ubuntu yang ingin di monitoring:

> sudo apt-get update
> sudo apt-get install -y curl gnupg apt-transport-https

curl -s https://packages.wazuh.com/key/GPG-KEY-WAZUH \
  | sudo gpg --no-default-keyring \
  --keyring /usr/share/keyrings/wazuh.gpg \
  --import

> sudo chmod 644 /usr/share/keyrings/wazuh.gpg

echo "deb [signed-by=/usr/share/keyrings/wazuh.gpg] https://packages.wazuh.com/4.x/apt/ stable main" \
  | sudo tee /etc/apt/sources.list.d/wazuh.list

> sudo apt-get update
Repository tersebut ditujukan untuk Wazuh 4.x. Sebelum instalasi, pastikan versi Manager Anda sesuai.

## Instal dan daftarkan agent
=============================
Jalankan:
sudo env WAZUH_MANAGER="192.168.3.5" \
  WAZUH_AGENT_NAME="ubuntu-192-168-3-10" \
  apt-get install -y wazuh-agent

Catatan
- WAZUH_MANAGER="192.168.3.5" (Server Yang terinstall Wazuh)
- WAZUH_AGENT_NAME="ubuntu-192-168-3-10" (Nama nanti yang akan muncul di summary)


## Aktifkan agent
==========================
> sudo systemctl daemon-reload
> sudo systemctl enable wazuh-agent
> sudo systemctl start wazuh-agent

Periksa statusnya:
==================
> sudo systemctl status wazuh-agent

Pastikan hasilnya active (running).
