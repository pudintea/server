INSTALL
=======
> sudo apt update && sudo apt upgrade -y
> sudo apt install nginx -y
> sudo systemctl status nginx
> sudo ufw allow 'Nginx Full'


Hardening Dasar Nginx
=====================
Sembunyikan versi Nginx
Edit file:
> sudo nano /etc/nginx/nginx.conf

Tambahkan:
server_tokens off;


Batasi request (anti DDoS ringan)
==================================
Tambahkan didalam : http {:

  server_tokens off;
  limit_req_zone $binary_remote_addr zone=one:10m rate=10r/s;
  server {
  
      limit_req zone=one burst=20 nodelay;
  
      add_header X-Frame-Options "SAMEORIGIN" always;
      add_header X-Content-Type-Options "nosniff" always;
      add_header Referrer-Policy "no-referrer-when-downgrade" always;
  
      add_header Content-Security-Policy "default-src 'self';" always;
      add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
  
  }


UPDATE NGINX
===============
ika menggunakan repository Ubuntu standar:
> sudo apt update && sudo apt upgrade nginx -y


Atau untuk memastikan paket terbaru:
> sudo apt update
> sudo apt install --only-upgrade nginx


Cek versi sebelum dan sesudah update:
> nginx -v

Contoh output:
nginx version: nginx/1.24.0


Restart atau Reload Nginx
Setelah update:
> sudo systemctl restart nginx



Proteksi Tambahan Install Fail2Ban (anti brute force)
======================================================
a. Install Fail2Ban (anti brute force)
sudo apt install fail2ban -y

Enable:
> sudo systemctl enable fail2ban

b. Nonaktifkan service tidak perlu

Cek:
sudo systemctl list-unit-files --type=service



Buat konfigurasi Minimal local fail2ban
=======================================

> sudo nano /etc/fail2ban/jail.local

ISI MINIMAL :
[nginx-http-auth]
enabled = true
port = http,https
logpath = /var/log/nginx/error.log
maxretry = 5
bantime = 3600

ATAU AGAK LENGKAP :

[DEFAULT]
bantime = 30m
findtime = 10m
maxretry = 5
backend = systemd

# Optional (lebih ketat)
bantime.increment = true
bantime.factor = 2

[nginx-http-auth]
enabled = true
port = http,https
logpath = /var/log/nginx/error.log

[nginx-badbots]
enabled = true
port = http,https
logpath = /var/log/nginx/access.log

[nginx-req-limit]
enabled = true
port = http,https
logpath = /var/log/nginx/error.log
maxretry = 10


RESTART
> sudo systemctl restart fail2ban



========== PHP MYADMIN ============

> sudo nano /etc/nginx/sites-available/pma.alazhar.eu.org
Masukan : 
server {
    listen 80;
    listen [::]:80;

    server_name pma.alazhar.eu.org;

    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;

    server_name pma.alazhar.eu.org;

    root /var/www/pma;
    index index.php index.html index.htm;

    ssl_certificate     /etc/cloudflare/alazhar.eu.org.pem;
    ssl_certificate_key /etc/cloudflare/alazhar.eu.org.key;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_prefer_server_ciphers off;

    add_header X-Frame-Options SAMEORIGIN;
    add_header X-Content-Type-Options nosniff;
    add_header Referrer-Policy no-referrer-when-downgrade;

    client_max_body_size 100M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.4-fpm.sock;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }

    access_log /var/log/nginx/pma_access.log;
    error_log  /var/log/nginx/pma_error.log;
}

> sudo ln -s /etc/nginx/sites-available/pma.alazhar.eu.org /etc/nginx/sites-enabled/
> sudo nginx -t
> sudo systemctl reload nginx
