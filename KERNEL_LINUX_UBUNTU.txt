== UPDATE KERNEL ==

> apt update && apt upgrade -y

Melihat list semua kernel dan kernel aktif
> dpkg --list | grep linux-image
> ls /boot/vmlinuz-*

Perhatikan :
6.8.0-147-generic
berarti sistem sedang menjalankan kernel tersebut.


Gunakan kernel terbaru, ini perintahnya
> sudo update-grub
> sudo reboot


Kalau kernel baru sudah jalan,
hapus kernel lama

> sudo apt remove linux-image-6.8.0-124-generic
atau
> sudo apt purge linux-image-6.8.0-117-generic linux-image-6.8.0-124-generic

> sudo apt autoremove --purge
> sudo reboot

Jangan hapus semua kernel yang tidak digunakan, minimal sisakan 1 kernel untuk antisipasi jika gagal boot.
