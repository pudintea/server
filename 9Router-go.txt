# 9 Router Golang

Link Download : https://github.com/luqman-v1/9router-go/releases/tag/v1.9.10
> wget https://github.com/luqman-v1/9router-go/releases/download/v1.9.10/9router-go-linux-amd64
> chmod +x 9router-go-linux-amd64

Jalankan Sementara :
> ./9router-go-linux-amd64

Aksess : http://IP_ADDRESS:20130
Pass : 123456 (Default)


====== BUAT SYSTEMD =======

> sudo nano /etc/systemd/system/9routergo.service

isikan ini
==========================================================
[Unit]
Description=9Router Golang
After=network.target

[Service]
Type=simple
User=pudin
Group=pudin

# Folder dimana binary dan .env berada
WorkingDirectory=/home/pudin/9router-go/

# Jalankan binary
ExecStart=/home/pudin/9router-go/9router-go-linux-amd64

# Auto restart jika crash
Restart=always
RestartSec=5

# Security
NoNewPrivileges=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target


==========================================================

Reload System
> sudo systemctl daemon-reexec
> sudo systemctl daemon-reload
> sudo systemctl start 9routergo
> sudo systemctl status 9routergo
> sudo systemctl enable 9routergo

Cara Lihat Log
> sudo journalctl -u 9routergo -f

Cara restart aplikasi
> sudo systemctl restart 9routergo


============ INSTALL HERMES ================
Saran sebelum install di 9Router sudah buat "combo & Vision Adapter"

> curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
> source ~/.bashrc
> hermes doctor   # cek semua dependency oke
> hermes # Untuk mulai ber komunikasi


Atau Bisa seperti ini, Sama saja :
> curl -fsSL https://hermes-agent.nousresearch.com/install.sh -o /tmp/hermes-install.sh
> bash /tmp/hermes-install.sh --skip-browser --skip-computer-use
> source ~/.bashrc
> hermes doctor   # cek semua dependency oke
> hermes # Untuk mulai ber komunikasi


Tahapan Install Hermes
- Full Setup
- Provider : Custom
- Masukan Base Url 9Router
- Masukan Api Key dari 9Router
- API Compatibility mode : 1
- Pilih API Combo yang sudah kita buat. Biasanya : 1 (sesuaikan)
- Context Length in tokens : Enter aja
- Display name : 9Router (Bebas)
- Select Reasoning effort : medium
- Select terminal backend : Keep Curent (local)
- Select platform to configure : Telegram (siapkan ID Boot dan ID Account Telegram)
- Pilih 2 atau manual
- Tools for CLI : Enter aja
- Choose a provider : Local Browser
- Choose a provider : Skip - keep default / configure later
- Choose a provider (Suara) : Microsoft Edge TTS
- Selest Search Provider : DuckDuckGo


Connect ke Telegram bot
Satu gateway process buat Telegram (dan platform lain kalau mau).

> hermes gateway setup
# ikutin wizard: pilih Telegram, masukin Bot Token dari @BotFather
> hermes gateway install
> hermes gateway start
> hermes gateway status
