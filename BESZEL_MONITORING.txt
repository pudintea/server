MONITORING DENGAN BESZEL
Saya menggunakan STB HG680P, Saya Install CasaOS untuk install Beszelnya,


TUTORIAL

# AGENT BINARY
=============
## DI DASHBOARD BESZEL
===================
Tambah System > Binnary >  Isi Nama > Isi Ip server yang akan di monitoring > 
Port : 45876
Amankan/Simpan Kunci Public dan Token
Klik Tambah System


## DI SERVER YANG AKAN DI MONITORING
=================================

### Download Binnary Agent
=======================
Download Beszel Agent Binnary Sesuai dengan system kalian :
Link : https://github.com/henrygd/beszel/releases/

Cek menggunakan apa :
> uname -m

Jika hasilnya
x86_64
gunakan amd64.

Jika
aarch64
gunakan arm64.

Link Download
> mkdir -p /opt/beszel && cd /opt/beszel
- x86_64  = wget https://github.com/henrygd/beszel/releases/download/v0.18.7/beszel-agent_linux_amd64.tar.gz
- aarch64 = wget https://github.com/henrygd/beszel/releases/download/v0.18.7/beszel-agent_linux_arm64.tar.gz


### Extract
========
Misal :
> tar -xzf beszel-agent_linux_amd64.tar.gz

Biasanya akan menghasilkan file
beszel-agent

Buat executable
> chmod +x beszel-agent

4. Pindahkan ke folder system
> sudo mv beszel-agent /usr/local/bin/ && cd /usr/local/bin
Pindah :
cd /usr/local/bin/

Cek
> beszel-agent --help

Kalau berhasil akan muncul daftar command.


### Membuat user khusus
========================
Disarankan tidak menjalankan agent sebagai root.
sudo useradd \
-r \
-s /usr/sbin/nologin \
-d /var/lib/beszel-agent \
beszel

Buat folder data
> sudo mkdir -p /var/lib/beszel-agent && sudo chown beszel:beszel /var/lib/beszel-agent

Ubah owner
> 


TEST SEMENTARA
===============
Masih posisi di dalam folder /usr/local/bin/
Masukan perintah ini :
> ./beszel-agent -key "<public key>" -token "<token>" -url "<hub url>"

Misal :
> ./beszel-agent -key "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIKLlQWaUVESaDDp/P1E3BTFShqwV2AUzKqc" -token "ffb6d8c7-2dfe-4d59-a2e2-099a9" -url "http://localhost:8090"

Jika sesuai, harusnya di dashboard akan menyala/Hijau



### BUAT SERVICE
Buat file :
> nano /etc/systemd/system/beszel-agent.service
Masukan ini :
[Unit]
Description=Beszel Agent Service
After=network-online.target
Wants=network-online.target

[Service]
User=beszel
Group=beszel
ExecStart=/usr/local/bin/beszel-agent
Environment="LISTEN=45876"
Environment="KEY=<public key>"
Environment="TOKEN=<token>"
Environment="HUB_URL=http://localhost:8090<SESUAIKAN>"
# Environment="EXTRA_FILESYSTEMS=sdb"
Restart=on-failure
RestartSec=5
StateDirectory=beszel-agent
WorkingDirectory=/var/lib/beszel-agent

# Security/sandboxing settings
KeyringMode=private
LockPersonality=yes
NoNewPrivileges=yes
ProtectClock=yes
ProtectHome=read-only
ProtectHostname=yes
ProtectKernelLogs=yes
ProtectSystem=strict
RemoveIPC=yes
RestrictSUIDSGID=true

[Install]
WantedBy=multi-user.target

**) PERHATIKAN KEY, TOKEN, HUB_URL, harus di sesuaikan.


Services
> sudo systemctl daemon-reload
> sudo systemctl enable beszel-agent.service
> sudo systemctl start beszel-agent.service
> sudo systemctl status beszel-agent.service
> sudo systemctl restart beszel-agent.service
