Install Ollama
Jalankan di terminal server:
> sudo apt update
> sudo apt install -y curl
> sudo apt-get install zstd

> curl -fsSL https://ollama.com/install.sh | sh
> sudo systemctl status ollama
> ollama --version


Download model coding
> ollama pull qwen2.5-coder:3b

Lalu tes modelnya:
> ollama run qwen2.5-coder:3b


Cek API Ollama
Buka terminal lain atau keluar dari sesi model, lalu jalankan:
> curl http://127.0.0.1:11434/api/tags

Jika muncul JSON yang mencantumkan qwen2.5-coder:3b, berarti API Ollama bisa diakses secara lokal.


Untuk server RAM 8 GB, saya sarankan mulai dari model-model berikut.
